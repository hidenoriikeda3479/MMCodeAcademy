## 1 今日のゴール

プログラムの「入力 → 処理 → 出力」の流れを理解し、変数に値を入れ、計算した結果をコンソール画面に表示できるようになることです。

## 2 実現したい動き／学んだこと

- Visual Studioで「HelloWorld」というコンソールアプリのプロジェクトを作成し、「Hello World」や「こんにちは」を表示する。
- `Console.WriteLine`と`Console.Write`を使い分けて、改行の有無を変える。
- 整数を扱う`int`、文字列を扱う`string`の変数を作り、値を入れて表示する。
- 変数同士の足し算と、数字の文字列を整数に変換する方法を学ぶ。

## 3 考え方

### 入力したデータを処理して出力する

プログラミングは、コンピュータに手順を正確に伝えることです。たとえば、10と11を用意するのが入力、それらを足すのが処理、結果の21を表示するのが出力です。

Visual Studioは、コードを書き、実行し、エラーを確認するための作業場です。

### 変数は値を入れる箱

変数を作ることを「宣言」、値を入れることを「代入」と呼びます。`int boxA;`が宣言、`boxA = 10;`が代入です。まとめて書くこともできます。

```csharp
int boxA = 10;
int boxB = 11;
int boxC = boxA + boxB;
Console.WriteLine(boxC);
```

`boxC`には計算結果の21が入り、画面にも21が表示されます。`=`は、右側の値を左側の変数に入れる記号です。

### 数字と数字の文字列を区別する

`1`は整数、`"1"`は文字列です。見た目が似ていても型が違います。数字の文字列を整数として扱いたいときは、`int.Parse`で変換します。

```csharp
string box1 = "1";
int number = int.Parse(box1);
Console.WriteLine(number);
```

`Console.WriteLine`は出力した後に改行します。`Console.Write`は出力した後に改行しません。

## 4 注意点

- 今回の宣言・代入・出力の文は、末尾にセミコロン`;`を付ける。
- 文字列を直接書くときは、`"こんにちは"`のようにダブルクォーテーションで囲む。変数の名前そのものは囲まない。
- 変数の型に合う値を入れる。文字列をそのまま`int`に代入せず、必要な変換を考える。
- 同じ範囲で変数名を重複させない。慣れてきたら、名前を保存する`myName`など、用途が分かる名前を付ける。
- 各変数に今どんな値が入っているかを追う。エラーは見直すヒントと捉え、分からなければLINEで講師に質問する。
